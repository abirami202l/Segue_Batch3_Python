# Set 3 – Hospital Appointment Desk## Task 1: Linear Search and Binary Search20,000 patient records are used.Linear Search:- Checks each patient one by one.- Best: O(1)- Average: O(n)- Worst: O(n)Binary Search:- Divides sorted records into two halves.- Best: O(1)- Average: O(log n)- Worst: O(log n)Space Complexity: O(1) for both iterative algorithms.Binary Search is more efficient for repeated lookups.## Task 2: Selection Sort and Quick SortAppointments are sorted using:1. Urgency level.2. Arrival time.Selection Sort:- Best: O(n²)- Average: O(n²)- Worst: O(n²)- Space: O(1)Quick Sort:- Best: O(n log n)- Average: O(n log n)- Worst: O(n²)- Space: O(log n) average recursion stack.Selection Sort finds the minimum elementand places it in the correct position.Quick Sort partitions the list around a pivot.## Task 3: Double-Booking DetectionA Set is used to detect duplicate bookings.Duplicate condition:- Same patient ID.- Same appointment slot.Time Complexity: O(n) average.Space Complexity: O(n).A Set provides fast membership checking.A list scan would require O(n) lookup timefor every new booking, resulting in O(n²)total time in the worst case.## Task 4: Queue and StackQueue:- FIFO (First In, First Out).- Used for walk-in patient tokens.Stack:- LIFO (Last In, First Out).- Used for recently viewed patients.Queue operations:- Enqueue: O(1) append.- Dequeue: O(n) using list.pop(0).Stack operations:- Push: O(1).- Pop: O(1).Built-in deque provides efficient queue operations:- Enqueue: O(1).- Dequeue: O(1).## Task 5: Dynamic ProgrammingThe objective is to maximize the number ofnon-overlapping appointments during a doctor's shift.Each appointment has:- Start time.- End time.Greedy Approach:Selects the appointment that finishes earliest,then selects the next compatible appointment.Dynamic Programming:Calculates the maximum number of compatibleappointments using previously calculated results.DP recurrence:dp[i] = max(    1 + dp[p(i) + 1],    dp[i - 1])Where:- p(i) is the previous compatible appointment.- Include means selecting the current appointment.- Exclude means skipping the current appointment.Time Complexity:- Sorting: O(n log n)- Finding previous appointments: O(n²)- DP calculation: O(n)Total: O(n²).Space Complexity: O(n).Both greedy and DP produce an optimal maximumappointment count for this unweighted intervalscheduling problem.DP also provides a framework for extensionssuch as appointment priorities and weightedscheduling.
