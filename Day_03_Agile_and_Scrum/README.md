## How to use the files
1. Open the relevant project folder.
2. Complete or personalise the six task files if your instructor requires team names, dates or institution details.
3. Use the Jira setup instructions to enter epics, stories, priorities, points and acceptance criteria in your own Jira project.
4. The Jira instructions are configuration guidance only; no real Jira project has been created by this assignment.
5. Keep the files separate when submitting if the assignment requires individual task deliverables.

## Quality checks
- Each project contains six non-empty task files.
- Story IDs use the required prefixes: GROC, INS and HOSP.
- Every story is linked to an epic and reviewed against all six INVEST criteria.
- Acceptance criteria use Given/When/Then format and include negative cases.
- Story point totals are calculated from the individual estimates.
- DoR and DoD are provided as practical checklists.
- No screenshots, diagrams, mock-ups or placeholder files are included.
