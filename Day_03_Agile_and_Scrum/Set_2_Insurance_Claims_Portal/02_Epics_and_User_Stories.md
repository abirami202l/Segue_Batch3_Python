# Set 2 – Epics and User Stories

## Epic overview

| Epic ID | Epic | Outcome |
|---|---|---|
| INS-E1 | Claim Registration | Policyholders can submit the basic information for a new claim. |
| INS-E2 | Document Upload | Policyholders can identify and submit supporting evidence. |
| INS-E3 | Claim Tracking | Policyholders can understand progress and required next actions. |
| INS-E4 | Settlement Notifications | Policyholders are informed of decisions and payment progress. |

## User story backlog

Exactly 14 stories are included to provide balanced coverage of the four epics.

| Story ID | Epic | User story |
|---|---|---|
| INS-01 | Claim Registration | As a policyholder, I want to start a new claim so that I can report an insured event to the insurer. |
| INS-02 | Claim Registration | As a policyholder, I want to select the policy related to my claim so that the insurer can identify the cover involved. |
| INS-03 | Claim Registration | As a policyholder, I want to enter the incident date and description so that the insurer receives the basic facts of the event. |
| INS-04 | Claim Registration | As a policyholder, I want to review and submit my claim details so that I can confirm the information before registration. |
| INS-05 | Document Upload | As a policyholder, I want to see the documents required for my claim type so that I know what evidence to provide. |
| INS-06 | Document Upload | As a policyholder, I want to upload a supporting document so that the insurer can assess my claim evidence. |
| INS-07 | Document Upload | As a policyholder, I want to see whether each document was received so that I can identify missing submissions. |
| INS-08 | Document Upload | As a policyholder, I want to replace an unreadable uploaded document so that the insurer can review a clear copy. |
| INS-09 | Claim Tracking | As a policyholder, I want to view the current status of a claim so that I understand its progress. |
| INS-10 | Claim Tracking | As a policyholder, I want to view the latest claim update so that I know whether I need to take action. |
| INS-11 | Claim Tracking | As a policyholder, I want to view a request for additional information so that I can respond to the assessor. |
| INS-12 | Settlement Notifications | As a policyholder, I want to receive a notification when my claim status changes so that I do not need to check the portal repeatedly. |
| INS-13 | Settlement Notifications | As a policyholder, I want to receive a settlement decision notification so that I know the outcome of my claim. |
| INS-14 | Settlement Notifications | As a policyholder, I want to view the settlement amount and payment status when approved so that I understand what will be paid and when. |
